# NexPilot 0.2.1-beta.1

This beta package contains the full NexPilot WordPress plugin and companion MCP stdio bridge. The plugin retains the original `nexdev-site-connector` identity, connection storage, MCP routes, permissions, approval workflow, and maintenance capabilities. It is a different plugin from the earlier reduced Community package.

Install the WordPress ZIP through **Plugins → Add New → Upload Plugin**. The bridge is a separate download for clients that use stdio. Verify the published SHA-256 checksums before installation.

Full maintenance includes arbitrary PHP, SQL, WP-CLI, file, and administrator operations under an explicitly permitted connection and administrator-opened maintenance window. It is not a sandbox. Validate the installation in staging before production use.

Local behavior tests use WordPress/MySQL doubles; consult the release checklist for the required integration and security review evidence.
