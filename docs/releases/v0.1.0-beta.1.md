NexPilot Community provides a ready-to-install WordPress plugin ZIP and a companion MCP bridge for Node.js clients.

### Install

1. Download `nexpilot-community.zip` below and upload it through **Plugins → Add New → Upload Plugin** in WordPress.
2. Activate the plugin and create a connection under **Tools → NexPilot Community**.
3. Download `nexpilot-community-bridge.mjs` for your MCP client and follow the [connection guide](https://github.com/nexdev-team/NexPilot-Community#connect-an-mcp-client).

Minimum versions: WordPress 6.6, PHP 8.1, and Node.js 20 for the bridge. Verify the SHA-256 checksum files if transferring the release files between systems.
